# github-final-project

A calculator that calculates simple interest given a principal amount,
an annual interest rate, and a time period in years.

An individual learning project for IBM's
[Getting Started with Git and GitHub](https://www.coursera.org/learn/getting-started-with-git-and-github)
on Coursera.

## Inputs

- `p`: principal amount
- `t`: time period in years
- `r`: annual interest rate, expressed as a percentage

## Output

Simple interest, calculated using:

```text
simple interest = p * t * r / 100
```
